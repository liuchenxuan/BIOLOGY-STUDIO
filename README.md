# 生物研习

> 为理解而学，为成长而练。一个面向高中生物学习与教学管理的本地化学习工作台。

## 项目简介

“生物研习”将高中生物判断题练习、题库维护、错题复盘、学习分析与对抗挑战放进一个浏览器应用中。项目强调让练习获得反馈、让知识点清晰可见，并以本机使用和离线可用为产品方向。

## 面向对象

- **学生**：开展专注刷题、自主练习、双人对抗与错题复习，查看学习分析与挑战入口。
- **教师**：管理题库与知识点，批量导入和新建题目，查看学生、成绩与教学分析，并管理规则和数据备份。

## 主要功能入口

### 学生研习室
- 专注刷题与自主练习
- 学习花园、探索实验室
- 双人对抗、对抗游戏与攻擂大厅
- 我的错题本、综合排行榜、对抗段位榜
- 学习分析与使用说明

### 教师工作台
- 题库管理、批量导入、新建题目、知识点管理
- 学生管理、成绩记录、教学分析
- 综合排行榜、对抗段位榜、攻擂大厅
- 学习与题目治理、规则设置、备份与迁移

## 项目特点

1. **围绕生物学习**：聚焦高中生物判断题和知识点练习。
2. **学生与教师双入口**：学习活动和教学管理分区呈现。
3. **重视反馈**：通过错题、分析与对抗活动帮助回看学习过程。
4. **本机优先**：界面标示本机数据与离线可用，强调数据由使用者掌握。
5. **独立演示入口**：提供演示沙盒，便于了解应用流程。

## 适用场景

- 学生个人进行生物判断题练习和错题回顾。
- 教师整理本地题库、知识点与练习活动。
- 无网络或希望在本机开展的学习演示与课堂活动。

具体功能是否可用、数据能否跨刷新保留，需以运行版本与目标浏览器实测为准。

## 使用建议

- 首次使用先浏览“使用说明与更新”。
- 用演示数据熟悉操作，再导入实际题库。
- 定期导出并妥善保存备份；迁移或恢复前先检查备份内容。
- 教师对题目答案、解析和知识点标注进行审核。
- 避免在共享设备或公开材料中暴露学生个人信息。
